Inspect any MCP server from a static page

  1. Click Try the in-browser demo server, or paste the URL of a Streamable HTTP server that allows CORS.
  2. Pick a tool. Its form is generated from the JSON Schema.
  3. Tools with an MCP App render in a sandboxed iframe right here.

Local servers work too (http://localhost:3000/mcp): the page talks to them straight from your browser. Your server must send CORS headers and expose Mcp-Session-Id.
